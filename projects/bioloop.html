BioLoop

A nutrition and health tracking app that helps people log meals and understand the nutrients behind them.

FastAPI React TypeScript PostgreSQL Gemini

The problem

Most food trackers count calories well but say very little about the vitamins and minerals in what you eat. I wanted a tracker that makes those nutrients visible without hours of manual entry.

How it evolved

BioLoop started as a Streamlit prototype with a SQLite database. That was perfect for testing the idea, but it couldn’t grow into a real multi-page app, so I moved it to a FastAPI backend, a React and TypeScript frontend, and PostgreSQL.

Before building new features, I wrote a product requirements document and an implementation spec. Planned features include batch recipes, saved recipes that the AI names automatically, and a starter list of 25 nutrition markers.

How it works

The frontend talks only to the FastAPI backend. The backend owns the database and decides when to call Gemini, using a two-tier routing strategy for its AI requests.

Challenges and trade-offs

Rewriting the prototype cost time up front, but it gave me typed API contracts and a real database I can migrate safely.

What I’d change

I’d write the spec before the prototype next time. Several features would have been easier if I’d planned the data model first.
